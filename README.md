# 📱 Contact Book Manager

A simple and user-friendly **Contact Book Manager built with Python** that allows users to add, view, search, update, and delete contact information.

## 🚀 Features

* ➕ Add new contacts
* 📋 View all contacts
* 🔍 Search contacts by name or phone number
* ✏️ Update existing contacts
* 🗑️ Delete contacts
* 💾 Store contact information
* 📞 Manage phone numbers and email addresses
* 🖥️ Simple and easy-to-use interface

## 🛠️ Technologies Used

* **Python**
* **File Handling**
* **Functions**
* **Lists / Dictionaries**
* **Exception Handling**
* **Tkinter** *(if GUI version is used)*

## 📖 How It Works

The Contact Book Manager allows users to maintain their contact information.

A contact can contain details such as:

* 👤 Name
* 📞 Phone Number
* 📧 Email
* 🏠 Address

Users can perform different operations through the application:

```text
1. Add Contact
2. View Contacts
3. Search Contact
4. Update Contact
5. Delete Contact
6. Exit
```
